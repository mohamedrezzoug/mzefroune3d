          البيانات

          —

          باش يشوفو الناس التعديلات

          1. صدّر douars.json.
          2. طلّعو لـ GitHub فنفس الـ repo حدا index.html (Add file ← Upload files).
          3. الموقع كيقراه أوتوماتيكيا ملي يتحل.

          نفس الشي لـ osm.json: ملي تكون الطرقات تحمّلات مزيان، صدّرو وطلّعو. من بعد الموقع ما بقاش محتاج سرفورات OpenStreetMap، وكيتحل أسرع.

          التعديلات كتتحفظ فهاد المتصفح حتى تصدّرها. إلا مسحتي بيانات المتصفح قبل التصدير كيضيعو.
